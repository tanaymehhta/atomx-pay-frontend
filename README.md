# AtomX Pay — Frontend

Warm, emotional redesign of the AtomX Pay USD→INR remittance product. Two themed versions,
same layout and motion:

- **V1 — Warm ivory** (`home.html`, `dashboard.html`): bright ivory + coral, purple kept.
- **V2 — Purple + white** (`home-v2.html`, `dashboard-v2.html`): the original deep-violet brand on a white theme, orange chevron accent.

Open `index.html` for a version picker. Static HTML/CSS/JS, no build step. Shared brand system in `assets/`.
